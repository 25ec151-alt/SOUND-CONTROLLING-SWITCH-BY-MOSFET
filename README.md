# Sound Controlled Switch Using MOSFET

## Project Description
The Sound Controlled Switch Using MOSFET is an electronics mini project that uses sound signals to control an electrical output. A microphone detects sound waves and converts them into small electrical signals. These signals are amplified using a BC547 transistor and used to control an N-channel MOSFET, which acts as an electronic switch.

When a sufficiently loud sound, such as a hand clap, is detected, the MOSFET switches ON and activates the LED. When the sound signal decreases, the MOSFET switches OFF.

## Components Used
- Electret Microphone
- BC547 NPN Transistor
- N-Channel MOSFET
- LED
- Resistors
- Capacitors
- Breadboard
- Connecting Wires
- 9V DC Battery

## Working Principle
The microphone senses sound and generates a small electrical signal. The BC547 transistor amplifies this signal, which controls the gate of the MOSFET. The MOSFET switches the output LED ON or OFF based on the detected sound.

- Simple alarm circuits
- Basic home automation
- Electronic switching applications
